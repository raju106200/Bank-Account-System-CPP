# Bank-Account-System-CPP
A simple Bank Account Management System using C++ Object-Oriented Programming (OOP). It supports account creation, money deposit, withdrawal, balance checking, and account details.

# Bank Account System (C++)

## About
This is a beginner-level C++ mini project based on Object-Oriented Programming (OOP).

## Features
- Create Bank Account
- Deposit Money
- Withdraw Money
- Check Account Balance
- Display Account Details

## Concepts Used
- Classes and Objects
- Encapsulation
- Data Members
- Member Functions
- Switch Case
- Do-While Loop

## Technology
- Programming Language: C++
- Compiler: GCC / MinGW / CodeBlocks

## How to Run
1. Download the source code.
2. Open it in a C++ compiler.
3. Compile and run the program.
4. Follow the menu instructions.
